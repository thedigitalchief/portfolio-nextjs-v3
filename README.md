## Introduction 👋

This is my personal portfolio website, designed and built to showcase my projects, skills, and experience as a full-stack developer and data analyst. The site is built with Next.js and Tailwind CSS for performance and clean UI, TypeScript for maintainability, and Firebase for backend services and dynamic content.

The goal of this project is to keep the portfolio fast, scalable, and easy to iterate on as my work evolves.

---

## Tech Stack 🛠️

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **Firebase**
- **SendGrid**
- **Framer Motion**
